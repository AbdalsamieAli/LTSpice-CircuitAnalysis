# Electric Circuts Analysis Using LTSpice

A collection of electrical circuits performed using LTspice.

## Objectives

* Analyze electrical circuit behavior using LTspice.
* Examine voltage and current wave forms.
* Verify theoretical calculations through simulation.
* Develop practical skills in circuit analysis and simulation.

## Tools Used 

* LTspice - Powerful, Free circuit simulation software I use it for circuit design and simulation.
* Electrical Circuit Theory
